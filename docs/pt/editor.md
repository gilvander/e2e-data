# Editor de Código (DT Script Viewer)

## Visualizar scripts gerados
- Cada pipeline/transformação gera script DT
- Viewer mostra blocos `INPUT/SET/FILTER/OUTPUT`

## Estrutura
- Cabeçalho (metadados)
- Blocos por tabela
- Saídas nomeadas

## Limitações atuais
- Apenas leitura
- Não suporta edição inline ainda
